|===
|Description
|Cadastro de clientes e obras.  
+
Os clientes da empresa sao em boa parte pessoas juridicas (condominios, cartorios, distribuidoras), com CNPJ e pessoa de contato ("A/C"). O cadastro precisa atender tanto PF quanto PJ.  
+
Modulo folha: nao depende de nenhum outro modulo de negocio.
|Base package
|`br.com.obracerta.customers`
|Spring components
|_Services_

* `b.c.o.c.CustomerService` -- API do modulo de clientes. E por aqui que os demais modulos conversam com este.
|Aggregate roots
|* `b.c.o.c.Customer` -- Cliente da empresa. Pode ser pessoa fisica ou juridica.  
+
Tipo publico do modulo: outros modulos podem referenciar Customer, mas nao enxergam o repositorio nem nada dentro de customers.internal.
|===
